# 路线图

## 当前版本（v0.3）

- [x] 供应链场景搭建（Step 01）
- [x] 行为体性格配置（Step 02）：决策倾向/活跃度/影响力/画像 + 种子事件
- [x] 7 行为体 LLM 单世界仿真引擎
- [x] 行为体互动仿真（行动信息流 + 观察层 + 受限行动空间，MiroFish 式跨轮反应链）
- [x] 种子事件注入（initial_posts 式世界干预）
- [x] 5 种关键事件检测
- [x] 指标演化数据表与六维演化评估
- [x] Markdown 报告导出
- [x] RAG 文档导入与知识检索
- [x] SQLite 持久化与检查点恢复
- [x] 多厂商 LLM 支持（8 家厂商预设，全局统一生效厂商）
- [x] 跨平台自定义标题栏
- [x] 节点级状态追踪与供应链链路传播
- [x] 终端统一日志系统
- [x] 全链路 AI 集成：Step1 文档分析自动填写场景、Step2 AI 生成行为体配置与种子事件、Step4 AI 叙述式综合分析（公式评估保留，失败自动降级）
- [x] LLM 配置全局化：独立「设置」页（与项目列表/工作区平级），统一生效厂商，.env 持久化
